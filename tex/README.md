# The LaTeX edition

This is the survey formatted as a two-column IEEEtran paper, the shape robotics surveys take when
they are posted to arXiv and submitted to a journal. It is a separate edition from `paper/`,
which holds the markdown draft and its PDF. The markdown edition is kept because its numbers were
checked by eight reviewers; this edition restates the same work and can drift from it, so
`paper/` remains the reference until this one has been checked the same way.

## Build

```
python tools/make_bib.py --probe   # refs.bib from corpus/bib.json, and its compile probe
tools/build_tex.sh probe_bib      # check the bibliography alone: bibtex must be silent
tools/build_tex.sh                # pdflatex, bibtex, pdflatex twice; errors and overfull boxes
```

`tools/build_tex.sh` takes an optional document name and defaults to `main`.

Everything the build needs is in `tex/`. `sty/` carries `IEEEtran.cls` and `IEEEtran.bst` from
CTAN, because the class is not installed system-wide here.

## What is generated and what is written

| path | owner |
|---|---|
| `sections/*.tex` | converted from `paper/sections/*.md`, prose preserved |
| `tables/*.tex` | generated by `tools/make_tex_tables.py` from `corpus/rows/` |
| `figs/fig_*.tex` | the survey's own data figures, generated as TikZ by `tools/make_tikz_figures.py` |
| `figs/fig_codegap.tex`, `fig_penetration.tex`, `fig_reporting.tex`, `fig_trials.tex` | the three headline findings and the trial-count distribution, by `tools/make_finding_figures.py` |
| `figs/finding_numbers.tex` | the counts those four figures and their captions print, as macros, by the same script; a caption that prints a number recounts it |
| `figs/extracted/` | figure regions rendered from the source PDFs by `tools/extract_figures.py` |
| `figs/selected/` | the subset chosen for the paper, cropped, listed in `figs/SELECTED.md` |
| `figs/plates.tex` | one command per selected photograph, each carrying its source credit |
| `refs.bib` | generated by `tools/make_bib.py` from `corpus/bib.json` |
| `probe_bib.tex` | generated by `tools/make_bib.py --probe`; twenty citations across the topics and every entry type, built with `tools/build_tex.sh probe_bib` |

## The bibliography

`refs.bib` is generated, never edited. What an entry's type says about its source is the point of
`tools/make_bib.py`: a refereed venue is `@inproceedings` or `@article` and carries the arXiv
eprint when the version parsed was the preprint; a work with no venue is `@misc` whose
`howpublished` is the arXiv identifier, because it has not been refereed; a vendor product page, a
company announcement or a blog post is `@misc` with a note saying what kind of source it is and
when it was fetched, so that a manufacturer's claim cannot be mistaken for a paper. The six works
whose full text was never obtained say so in a note.

Citation keys in the markdown are written in backticks, and so are file names, config fields and
function names. `tools/mdtex_cite.py` tells them apart by looking the span up in `corpus/bib.json`:
`citeify(text)` rewrites a span that is a key as `\cite{key}`, merges a comma-separated run into
one `\cite{a,b}`, and leaves every other span in backticks for the converter to set as
`\texttt{}`. Section converters import it rather than matching keys themselves.

## Figure policy

The survey's own figures are drawn in TikZ, in greyscale with one muted accent, so they read as
part of the page rather than as screenshots. Each of the three headline findings has a figure
that states it on its own, so the argument can be read from the figures alone: the paper-against-code
funnel in Section 1, the reporting bars in Section 7.1, and the penetration funnel, which ends at
zero, in Section 7.3. Photographs and simulator renderings are reproduced
from the source papers, each with its source stated in the caption.

No permission has been sought for any reproduced figure. `PERMISSIONS.md` is the register, and
every row currently says pending. Before this is posted or submitted, each figure needs a licence
that permits redistribution, a granted permission, or replacement by a redrawing. The build does
not enforce that.
